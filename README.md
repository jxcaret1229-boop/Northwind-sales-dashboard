# Northwind-sales-dashboard

This project uses **Power BI** to analyze the Northwind Traders dataset and transform raw sales information into clear, interactive business insights. The dashboard is designed to help users monitor revenue performance, customer distribution, and product sales trends through dynamic visualizations.

## Key Features

- **Sales Overview:** Displays Total Revenue generated from all recorded transactions.  
- **Customer Reach:** Tracks the number of customer cities included in the dataset.  
- **Sales Trends:** Monthly sales performance visualized across different years.  
- **Product Performance:** Highlights top-selling products based on revenue contribution.  
- **Product Volume Indicator:** Shows the total quantity of products sold.  
- **Geographical Insights:** Interactive world map displaying customer and sales locations.  
- **Country Filtering:** Allows users to explore results by selected countries.  

The main objective of this project is to demonstrate how Power BI can convert transactional sales data into meaningful dashboards that help identify patterns, top-performing products, and market presence across regions.
